# Repository settings for visibility

What to enter on GitHub when the repository is created. GitHub search weighs the repository name most, then the
description, the topics and the README.

## Name

`koernertom/fenn-focus` – the same name as the app, so links, stars and mentions all point to one brand. The search
words people use (*notch*, *ai*, *local LLM*, *pomodoro*) come from the description and the topics below.

## Description (About, max. 350 characters)

> Free, local-first AI assistant for your Mac's notch: tasks, calendar, Pomodoro focus timer, app blocker, routines
> and notes, plus Fenn, an agent that runs on-device with MLX, Ollama, LM Studio or Apple Intelligence. MCP server for
> Claude Code and Cursor. No account, no server. MIT.

## Topics (max. 20)

```
macos notch ai-assistant local-llm on-device-ai mlx ollama lm-studio mcp mcp-server
productivity pomodoro focus-timer app-blocker task-manager menubar-app swiftui
apple-intelligence qwen open-source
```

## Social preview

Settings › General › Social preview: upload `docs/social-preview.png` (1280 × 640). It shows when the link is shared on
X, LinkedIn, Slack or in messages.

## First release

- Tag `v1.0.0` with a signed and notarised DMG attached, so people can try it without Xcode. Release notes start with
  the one-line pitch and the agent GIF.
- Pin the repository on your GitHub profile.
- Enable Discussions for questions and model recommendations; keep Issues for bugs and features.
